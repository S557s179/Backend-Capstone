# FlyRank Embeddable Widget Platform

A backend platform for creating and managing embeddable JavaScript widgets.

## Features

- User registration
- Secure password hashing with bcrypt
- JWT authentication
- PostgreSQL database
- Widget CRUD operations
- Per-widget API keys
- User-based widget ownership
- Public widget configuration endpoint
- Embeddable JavaScript widget
